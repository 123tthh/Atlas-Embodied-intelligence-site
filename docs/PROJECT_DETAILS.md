# Embodied Atlas · 0.99 RC

具身智能研究地图，以技术关键词、时间、机构、实验室与人物组织具身智能研究；支持中英文界面。

站点：https://embodied-atlas.xyl1122.chatgpt.site

## 使用

- 团队技术图谱：默认进入团队总览，按地区、类型、研究方向和核验状态查找。当前 110 条通过核验的研究线（289 项去重成果），45 条待补证候选；每条主线可查看纳入理由与原始证据。最多并排四条研究线；联合论文可出现多列，计数去重；按团队或技术方向分列。NVIDIA GEAR 保留 21 项工作，包含此前列出的 GR00T 系列及 HOVER、ASAP、SONIC、VIRAL、DreamGen、DreamZero、DreamDojo、ENPIRE、RoboTTT。
- 技术图谱：纵向时间轴，按八个研究方向分列，新增世界模型、导航、运动控制、灵巧触觉和仿真。拖动画布，滚动浏览，Ctrl + 滚轮缩放；手机默认使用纵向阅读模式，也可切换自由画布。
- 点击论文查看原文、项目、代码、技术关键词、部分作者主页和 Scholar 检索链接。
- 实线表示有原始资料支持的扩展、蒸馏或资源使用；虚线表示编辑整理的同类比较。点击连线或详情旁的链接图标可查看依据。
- 支持会议 / 期刊、Best Paper、荣誉提名 / 入围、Oral、Spotlight、Highlight，以及年份、方向、关系筛选与一至两层关联展开；分享按钮生成可恢复筛选的链接。
- 论文索引最多支持三篇并排对比。机构页可从大学或公司进入实验室与代表人物；实验室与人物页支持中英文姓名、缩写、机构、领域筛选，姓名链接到个人主页或官方介绍。
- 访客收藏保存在当前浏览器；登录后使用独立的云端书架。两套书架不会自动合并，可先导出，再登录并导入。
- 发现页查询 arXiv 最新提交，最多返回 12 条。Scholar 和会议入口使用外部检索链接。
- 登录后提交研究；维护者审核通过后公开。每账户每天最多 20 条投稿，重复原文链接会被拦截。

## 目录范围与来源

当前精选库含 354 项 2016–2026 年研究与技术发布、137 条关系、8 个研究方向与 36 个子领域标签。机构人物目录含 158 个机构、120 个实验室/研究单位、108 位人物。成果索引含 344 项可归属的代表成果。核验日期 2026-10-13。这是代表性目录，不是完整文献库或人员名录。

团队准入登记在 `lib/team-reviews.json`：至少两项明确归属成果，并有同行评议或可检查评测；公司还需可检查技术材料，以及实机实验或明确的模型 / 仿真评测。模型与智能公司无需生产硬件；模型侧和实机证据分别标注，新兴公司逐项核验。作者报告实机实验不等于本站或第三方复现；待补证不表示团队没有成果。机构研究组合单独标记，不能等同于一个实验室；现任单位不能自动继承历史论文。新投稿和目录记录不会自动成为可选团队主线。

时间轴按最早核验的公开日期；精确日期未能核验时仅保留年份。正式发表年份及获奖年份单独记录。作者仅列部分关键人物，完整作者名单及最新机构归属以原文、个人主页为准。每篇论文和每条关系均保存来源链接。标为 arXiv 的条目表示本轮没有核验最终发表场所。

目录位于 `lib/catalog.json`，可在网站“关于这张地图”中导出完整 JSON。

## 数据与权限

浏览研究无需登录。ChatGPT 登录由 Sites 提供。云端收藏以站点内稳定用户标识隔离；投稿在待审核时仅提交者及维护者可见。通过审核的论文信息、关键词和关系依据公开，用户邮箱不随目录公开。

管理员由运行时 `ADMIN_EMAILS` 配置，源码不包含真实账户邮箱、登录令牌或本地数据库。非维护者无法批准投稿；请求来源、链接协议、字段长度和论文存在性由服务端校验。

## 开发与验证

运行环境：Node.js 22.13+，Vinext / React，Cloudflare Worker 与 D1。保留 `.openai/hosting.json` 中的站点身份。

```sh
npm run dev -- --hostname 127.0.0.1 --port 5173
npx tsc --noEmit
node tests/domain.mjs
node tests/directory.mjs
node tests/geography.mjs
node tests/regions.mjs
node tests/research.mjs
node tests/graph.mjs
npm run build
```

数据库迁移位于 `drizzle/`；首次本地运行需要应用迁移。Sites 发布包包含迁移，生产发布由 Sites 处理存储绑定。不要提交 `.dev.vars` 或 `.wrangler/`。

本地完整 API 验收需要在 5174 端口运行生产预览，并将测试管理员设置为 `qa-admin@sites.test`：

```sh
npm run start -- --port 5174 --var ADMIN_EMAILS:qa-admin@sites.test
python3 tests/api.py
```

该测试仅指向本机，不可用于线上站点。它模拟两个贡献者和一个维护者，验证收藏隔离、投稿可见性、审核、重复拦截与深链接。开发预览的本机模拟登录固定为 `seedy@sites.test`；线上由 Sites 注入真实身份。

## 当前限制

- 未提供论文全文镜像或自动引用网络生成；每周任务可将附原始来源核验记录的研究直接写入目录，技术关系与团队归属仍需独立审核。
- Google Scholar 和会议检索跳转外部网站；arXiv 受上游可用性影响，失败时提供原站入口。
- 目前没有管理员编辑已批准投稿、合并条目或完整版本历史界面；维护目录可通过更新种子数据并重新发布，社区投稿审核支持批准和拒绝。
- 0.99 为预发布版本，尚未经过大规模用户与负载测试。


## 更新与维护

网站“数据与更新”页说明实际数据路径：基础论文目录位于 `lib/catalog.json`，机构/实验室/人物位于 `lib/directory.json`，经原文和官方来源核验后随版本发布到云端。浏览器不是基础目录的唯一存储位置，也没有下载/托管论文全文。

- 社区论文：登录投稿 → 维护者核验 → 审核通过；云端数据库记录会自动并入公共目录，无需重发整站。
- 基础目录与机构人物：维护者修改上述版本化数据，保留来源、双语描述、关系类型与核验日期，完成检查后重新发布。
- arXiv 发现：按关键词实时查询；搜索结果不会自动入库。当前正式网站已启用每周二北京时间 10:00 的来源核验与自动收录任务。“刷新目录”只读取已发布数据。
- 登录书架与投稿在云端数据库持久化；访客书架只保存在当前浏览器。论文目录与人物目录均可从网页导出 JSON。

人物当前关系与论文署名机构独立记录。公司无可核验命名实验室时直接关联人物；创始关系不意味着现任管理职位。`homepageType` 区分个人网站、本人 GitHub 与机构官方介绍。`sources` 保存原始出处，任职变化应核验后更新，不能仅从旧论文推断。`lib/taxonomy.ts` 定义子领域，`lib/translations.json` 和语言组件维护中英文界面；语言偏好本地保存，分享链接可携带 `lang` 参数。

本站已使用 Sites 托管的云端运行环境与数据库，访问时不需要本地电脑持续运行，也不需要自行维护独立服务器。自行迁移则需兼容的网站运行环境和数据库。


## 世界地图

入口 `/?view=map`。世界地图使用 Natural Earth 公共领域陆地矢量，在本站渲染，无需地图服务密钥。位置覆盖 148 个机构条目、80 个实际城市或地点、20 个国家；位置依据为公开主校区、总部或办公城市，坐标为城市级近似位置。

地图与机构、实验室、人物页共同读取 `lib/directory.json`。机构的 `location` 保存 `lat`、`lon`、`cityZh`、`cityEn`、`locationType`、`precision: "city"`、`sourceUrl` 与 `verifiedAt`，可附 `noteZh` / `noteEn`、`metroZh` / `metroEn`（保留实际城市，用于明确的都会区比较）。校区单独采用 `locationType: "campus"`。更新目录并发布后，圆点、机构名单、实验室和人物计数同步更新，不维护第二份地图名单。新机构暂缺已核验坐标时，会进入“地点待核验”列表，不静默丢失或猜测位置。实验室在所属机构下列出；总部坐标不表示所有实验室和人员均在当地。

圆点面积随聚合中的已收录机构数量增长。缩放时按屏幕距离重新聚合；点击聚合点可缩放并列出其成员，同城市重合点保留可点击名单。拖动/滚轮/双指和键盘方向键、加减键、Home 可调整视图；缩放与平移时名单跟随范围更新，选择聚合点时列出选中区域。支持公司/大学/领域筛选、中英文、机构/实验室到人物页跳转，分享链接保留地图中心、缩放及筛选条件。动效尊重系统减少动画设置。

底图来源：Natural Earth `ne_110m_land`，公共领域；`lib/world-land.json` 为等距经纬投影的路径数据。官网与许可：https://www.naturalearthdata.com/about/terms-of-use/ 。


## 区域与产业研究

入口 `/?view=regions`。默认比较北京、香港、新加坡、亚特兰大都会区，支持最多四个城市/都会区或国家并列比较。机构类别、产业方向、研究领域和全局关键词共同作用于比较；机构筛选表另有国家与城市范围。公司、大学、研究机构、已收录实验室和公开人物分别计数，人物在每个区域内按 ID 去重；同一人物可出现在多个区域，不可直接相加为全球人数。

- 香港 8 个机构、新加坡 10 个机构；亚特兰大都会区 5 个机构，包括 Atlanta、Norcross、Roswell、Suwanee 的已核验地点。实际城市保留在地图和导出表中。
- 产业标签为编辑归类，位于机构记录 `sector`；不是工商登记行业或企业评级。机构、办公室、业务部门和大学校区并非统一法人统计口径；不能据此推算就业、营收、产业规模或地区竞争力。
- 原始城市坐标与代表地点只描述一个公开主校区、校区、总部或办公室，不表示全部团队和人物均常驻当地。地图按实际坐标聚合；区域页按 `country` + `metroEn || cityEn` 分组，同名不同国家城市不会合并。
- 筛选结果、地图当前范围、研究清单可导出 UTF-8 CSV，含稳定 ID、官网、地点依据、来源链接、核验日期与口径说明；比较表导出包含机构 ID 及当前筛选条件。CSV 对公式前缀进行转义。
- 机构研究清单使用浏览器 `localStorage`（`atlas-institution-shortlist-v1`），与论文书架独立；不会自动跨设备同步。
- 所有视图读取同一个 `lib/directory.json`；更新与重新发布即可同步。没有另设自动抓取、公司估值或金融推荐。

本轮新增来源来自大学、实验室、公司和研究机构官方页面。多地点公司采用一处有明确来源的代表位置；双总部和办公地在地点说明中标注。关联公司可用 `parentOrganizationId` 表达，并附官方依据。

都会区为区域研究用途的编辑分组，不采用全球统一行政边界。相同国家与实际城市的条目使用相同分组；旧金山湾区参照 MTC/ABAG 的九县范围（https://census.bayareametro.gov/），保留各机构实际城市坐标。


## 以成果筛选机构与团队

入口 `/?view=works`。`lib/directory.json` 的 `works` 将代表论文、模型、数据集与基准关联到核验过的机构和实验室；联合工作只保留一个成果记录，可关联多方。成果索引与技术演化图谱分别维护，新增成果不会自动生成技术关系。机构与成果缺失表示尚未补齐核验，不是没有研究产出。

- 地图、区域比较、机构目录默认筛选“有代表成果”，可切换“全部机构目录”。同行评审、公开权重、代码和数据可独立筛选。区域成果数按成果 ID 去重，不把联合工作重复计入区域总数。
- 原始论文、会议记录、机构项目、Hugging Face 模型卡和官方仓库为证据；`discoverySources` 保存发现线索。X 检索入口用于继续发现，不代表自动抓取或已核验社交动态。
- 质量信号是明确、可检查的事实，不生成统一质量分或用社交热度排名。区分同行评审、预印本、企业技术发布；“公开权重”不表示无许可约束或全面开源。
- 成果署名与当前人员任职分别维护；只关联已有来源的参与单位，不推断完整作者机构列表。多地公司和研究院的地图点只表示标明的总部、办公室或校区；实验室与团队不必全部常驻该点。
- 成果导出含原始链接、关联机构/团队、证据标签和核验日期。筛选与分享链接可恢复成果类型、机构、关键词和证据条件。


## 2026-10-13 技术图谱补录

原有机构成果与技术目录现已按稳定 ID / 原始论文地址合并核验，确保代表成果可进入技术图谱。图谱现有 171 项成果、94 条关系，36 项带官方重点展示或奖项记录；各类荣誉保留精确名称、年份和依据，workshop 荣誉单独注明。覆盖 ICRA、IROS、IEEE RA-L、T-RO、Science Robotics、RSS、CoRL、CVPR、ECCV、ICCV 等，并在“数据与更新”保留 21 个会议 / 年份的检索入口。检索截止为 2026-10-13（Asia/Shanghai），这是有来源的代表性补录，不是所有 proceedings 或 X 宣发的完整镜像。

GEAR 核验了官方成果目录、项目、论文、代码和 Hugging Face 模型卡。部分官方项目直链的 X 宣发正文无法抓取，仅保存发现入口，不用社交转述证明技术、奖项或发布日期。ENPIRE、DrEureka 等最早原始公开日未能完整核验的条目保留年份精度。GR00T N2 的预告不作为已发布模型入库。

`lib/graph-layout.ts` 独立处理多列、多年份与联合论文布局，`lib/team-graph.ts` 从已核验归属生成研究线，`lib/paper-evidence.ts` 区分获奖、候选与展示类别。没有以时间相邻、共同机构或相似名称生成算法继承边。

机构、地图和团队总览默认按已收录成果的证据权重排序：基础 1、同行评议 +4、机器人期刊 +2、公开代码/权重/数据各 +1（每项最多 +2）、2025–2026 年 +1；同一论文去重。这是库内浏览优先级，不是全量机构或个人排名。可切换发表数量、时间和名称排序。Researchers 页面支持已核验研究阶段筛选，12 位当前博士生附个人主页和明确代表作，当前身份与历史论文归属分开处理。

本轮继续扩展 75 项研究与技术发布、16 位有当前身份依据的在读研究者（学生筛选共 28 人），补入 Genie / SIMA / Cosmos、企业模型研究及亚洲、欧美高校连续成果。虚拟环境智能体、物理推理与实机验证分别标明；Predict2.5 与 Transfer2.5 共用报告只计一个研究节点。年份不明月日的记录只保留年份。
